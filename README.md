# Esplorazione Modelli Hugging Face 

Una collezione di notebook Jupyter e file py per sperimentare con modelli di visione artificiale e AI multimodale, con focus su rilevamento di deepfake e question answering visivo.

## 🚀 Setup Rapido

### Installazione Dipendenze
```bash
pip install transformers accelerate torch torchvision
pip install qwen-vl-utils[decord]==0.0.8
pip install kaggle
```

### Requisiti Hardware
- **GPU**: T4 o superiore (consigliato Google Colab)
- **RAM**: 8-12GB
- **Storage**: ~20GB per modelli e dataset

## 💡 Uso

I notebook sono progettati per essere eseguiti su **Google Colab** o **Kaggle** con GPU attivata. Seguire le celle in ordine per:
1. Installare le dipendenze
2. Caricare i modelli
3. Eseguire gli esperimenti

## 🎯 Scopo

Questo repository è un progetto di ricerca/apprendimento per:
- Testare capacità dei modelli vision-language
- Sperimentare tecniche di prompt engineering
- Valutare performance nella detection di contenuti AI-generated

## 📝 Note

- Repository a scopo educativo/sperimentale
- I modelli non sono production-ready
- Consultare le licenze dei singoli modelli su Hugging Face
